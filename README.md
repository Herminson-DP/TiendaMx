# TiendaMx

Tienda online completa migrada a Node.js y Express con plantillas EJS.

## Características

- **Catálogo de Productos**: Búsqueda por nombre y especificaciones, filtrado por categorías, cálculo de descuentos y badges de categoría.
- **Carrito de Compras**: Gestión de cantidades, subtotal, cálculo de impuestos configurables y costos de envío.
- **Proceso de Pago (Checkout)**: Formulario de datos del cliente, resumen del pedido y generación de orden.
- **Recibo de Compra**: Vista de confirmación detallada con ID de orden, cliente, productos y total pagado.
- **Historial de Órdenes**: Registro de todas las compras realizadas con desglose desplegable.
- **Panel de Administración**: Agregar y editar productos con imágenes, precios, especificaciones y descuentos; configuración del nombre de la tienda, tasa de impuestos y costos de envío.

## Ejecución

```bash
npm install
npm run dev
```

La aplicación se ejecuta en el puerto 3000 (`http://localhost:3000`).
